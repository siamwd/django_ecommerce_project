# 🛒 ElyCart - Django E-commerce Project

A modern E-commerce web application built with Python and Django.  
This project includes user authentication, product management, shopping cart functionality, and a scalable backend structure for real-world eCommerce development.

---

## 🚀 Features

- 🔐 User Authentication System
- 🛍️ Product Listing & Details
- 🛒 Shopping Cart System
- 📦 Order Management
- 👤 User Profile Management
- 🧾 Django Admin Dashboard
- 📁 Clean Project Structure
- ⚡ Scalable Django Architecture
- 🎨 Responsive Frontend UI

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/siamwd/django_ecommerce_project.git
```

### 2️⃣ Move into Project Folder

```bash
cd django_ecommerce_project
```

### 3️⃣ Create Virtual Environment

```bash
python -m venv env
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
env\Scripts\activate
```

#### Mac/Linux

```bash
source env/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run Migrations

```bash
python manage.py migrate
```

### 7️⃣ Start Development Server

```bash
python manage.py runserver
```
